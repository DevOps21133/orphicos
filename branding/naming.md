# OrphicOS — Naming & Language System

One product, one vocabulary. Every surface — UI, docs, marketing, support replies, tweets — uses the same words.

## Names

| Thing | Name | Rules |
|---|---|---|
| The product | **OrphicOS** | Capital O, capital OS, one word. Never "Orphic OS," "OrphicOs," or "Orphic." In the serif wordmark it is rendered "orphicOS"; in running text always "OrphicOS." |
| The hosted decision service | **the OrphicOS brain** (preferred) or **the OrphicOS engine** | Always with the article and the brand: "the OrphicOS brain," never bare "the brain" in public copy, never "the AI," never "the model," never a provider or model name — anywhere, ever. |
| The software on the user's PC | **the OrphicOS client** or just **OrphicOS** | Users don't need the client/server split explained unless they ask; when we explain it: "a thin client on your PC executes; the OrphicOS brain decides." |
| The name itself | — | "OrphicOS" is a name, nothing more. Never explain it, never build story on it, never reference mythology. The ship/storm artwork is visual identity only — do not mythologize it in copy. |

## Tagline

**"the machine works. You don't."** — fixed, verbatim.

Usage rules:
- Lowercase "the," capital Y in "You," period after both clauses. Never reworded, extended, or "improved" ("the machine works so you don't have to" is banned).
- Full form for headers/marketing: **OrphicOS — the machine works. You don't.**
- It is a statement of division of labor (user supplies intent, machine supplies execution), not a promise of autonomy. Never pair it with "hands-off," "fully autonomous," or "set and forget" copy.
- Don't use it as filler in body text; it appears once per surface (hero, sign-off, or wordmark lockup), not sprinkled.

## Glossary — say this, not that

| We say | We avoid | Why |
|---|---|---|
| command | prompt | Users command a machine; "prompt" exposes the LLM plumbing. |
| the user **speaks** / **says** / **types** | dictates, prompts, queries | Plain verbs; matches the tagline's voice. |
| the machine **works** / **does it** / **executes** | the AI performs, the agent handles | The subject is "the machine" or "OrphicOS," never "the AI." |
| the OrphicOS brain | the LLM, the model, [any provider name] | Rule 2: provider is an internal detail. |
| the OrphicOS brain **decides** the actions | thinks, reasons, understands | "Decides" is accurate and modest. |
| reads the interface / reads the screen's structure | scrapes, watches you, sees everything | Accurate (UI Automation tree) and non-creepy. |
| live log | telemetry, trace, chain of thought | It's the user's window into what's happening. |
| kill switch | emergency stop, panic button | One name, used everywhere, matching the UI. |
| approval gate / confirm gate | safety rails, guardrails | Concrete mechanisms, not vibes. |
| sign in | set up, configure, enter your API key | Onboarding is: install → sign in → speak. There is nothing to configure. |
| early access | beta (fine internally), launch, v1 | Honest stage-setting; no implied maturity. |
| "Processed securely on OrphicOS servers. Encrypted in transit. Your screen data is never stored." | "runs locally," "offline," "never leaves your machine," "private by default" | Rule 3: the approved claim, verbatim, is the only data claim. |
| "Your voice is transcribed on your device" | "your voice is private" (vague) | The one on-device claim we may make, stated precisely. |
| agent-free vocabulary: "OrphicOS," "the machine" | agent, agentic, copilot, autopilot, autonomous | Hype-cycle jargon; also implies autonomy we deliberately don't offer. |

## Voice and tone

- Plain, precise, dry. Anthropic/Stripe register: short declaratives, no exclamation marks, no hype adjectives ("revolutionary," "magical," "blazingly").
- Present tense, active voice: "You speak. The machine works."
- The machine is "it," never "he/she"; OrphicOS has no persona, no chatty first-person UI copy.
- Every capability claim is true today or marked "(future)".
