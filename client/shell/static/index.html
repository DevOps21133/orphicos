🕸 Orphic Page Agent

Orphic Page Agent is part of the OrphicOS Base Premium plan — voice/text-driven web navigation, right in the page. Upgrade to unlock it.

A premium feature. See plans

Orphic Page Agent gives you voice/text-driven web navigation inside this page. It bridges to the open-source page-agent library (MIT). Opt-in: off by default; OrphicOS's normal path (local speech-to-text → the OrphicOS brain) is unchanged unless you turn this on.

page-agent runs its own reasoning loop in your browser, so it needs a provider key you supply. The key stays in this browser's localStorage and is never sent to OrphicOS servers.

Scope: page-agent can only drive the page it's loaded into. In the OrphicOS shell that means it can operate the shell itself (e.g. "scroll the log", "open memory", "press run"). Driving a third-party site requires loading it there.
